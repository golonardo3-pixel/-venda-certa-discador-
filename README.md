# Venda Certa Discador

Protótipo inicial independente dos projetos de sites Lovable.

## Recursos
- Importação local de CSV com colunas empresa, telefone e cidade (vírgula ou ponto e vírgula).
- Abre o discador do Android via link tel: (usuário confirma a chamada).
- Classificação de resultados e exportação CSV.
- Sem backend e sem upload de leads.

## Limites
Não realiza chamadas automáticas, detecção de pessoa atendendo ou transferência automática. Isso exigiria componente Android nativo/telefonia e testes de compatibilidade e conformidade com operadora e regras aplicáveis.

## Visualização
Abrir index.html no navegador ou usar GitHub Pages quando habilitado. Não depende do Lovable nem Vercel.
